# Video Frames, Export Audio and Motion-Path Easing — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw video layers frame-accurately, put every audio layer and unmuted video sound into exported files (and preview), and let motion paths ease and move at constant speed.

**Architecture:** Three independent features on four stacked branches, in spec §6 order. F3 rewrites `motion-path.ts` around an arc-length table and applies `getEasing()` before evaluation. F2 export computes per-layer timing in TypeScript (`audio-tracks.ts`) and turns it into one FFmpeg filter graph in Rust (`build_audio_filter`). F1 adds an async *prepare* pass (`prepareVideoFrames`) that fills a WebCodecs frame cache (mediabunny, adapted from OpenCut Classic's `VideoCache`) before the existing synchronous draw. F2 preview rewrites `AudioEngine` on the same timing helper as the export. A debug-only e2e hook (`LCS_E2E`) lets scripts drive real exports in the real webview, so every acceptance check runs automatically.

**Tech Stack:** TypeScript, React 19, Canvas 2D, Vitest + node-canvas, mediabunny 1.61.3 (WebCodecs), Web Audio, Rust (Tauri v2), FFmpeg 8.1 (spec checked 6.1).

**Spec:** `docs/superpowers/specs/2026-10-10-video-audio-motion-path-design.md`

## Decisions made while planning (not spelled out in the spec)

- **Motion-path helper.** Easing is applied in `motionPathAt(path, frameInLayer, layerDuration)` in `motion-path.ts`, which `draw.ts` calls. That keeps R3.2's maths testable; `draw.ts` still does no other path maths.
- **Overshoot.** Non-looping paths extrapolate along the end tangent (R3.2's preferred option) in both timing modes.
- **Easing menu.** The keyframe editor's grouped list moves to `src/lib/easing-options.ts` and both menus import it (R3.5 "same options").
- **Audio clipped to its scene.** A layer whose `endFrame` runs past its scene's end stops at the scene end, as its visuals do. The spec formula `(endFrame − startFrame) / fps` is used with `endFrame` clamped to `durationFrames`.
- **Audio ends with the video (found during B8).** The spec's graph ends in a bare `apad` and relies on `-shortest`. With frames arriving at render pace, FFmpeg 8.1 then let the audio run 0.5 s past the video (5.546 s against 5.000 s; 4.48 s against 3 s in a paced Rust test). The graph now ends in `apad=whole_dur=D,atrim=end=D` with D = total frames / fps, so `build_audio_filter` and `build_ffmpeg_args`/`spawn_ffmpeg` take the output length. `-shortest` stays as a guard.
- **PNG export needed a write permission (found during C7).** `src-tauri/capabilities/default.json` granted fs reads and `mkdir` but not `write_file`, so every PNG-sequence export failed with "fs.write_file not allowed" (on `main` too). F1 adds `fs:allow-write-file`; writes stay limited to the runtime scope (dialog-picked folders, opened projects). `write_text_file` (project Save) is still not granted — left for a follow-up.
- **Live playback check is scripted (D3).** Instead of clicking through the GUI, a `play` e2e job presses play in the real workspace and records every `AudioBufferSourceNode.start()` call with the context state.
- **FFmpeg stderr.** FFmpeg now runs with `-hide_banner -nostats -loglevel error`, and a thread drains stderr. That surfaces errors (R2.5) and removes a latent hang: stderr was piped but never read.
- **Video cover clips to the box.** `drawVideoLayer` keeps the cover maths (R1.6) but clips to the layer box like image layers do, instead of spilling past it.
- **Frame cache changes from OpenCut.** Exact lookup (OpenCut accepts a frame up to 50 ms early), clamping to the track, `undefined` for superseded requests, remembered failures, an injectable sink for tests, and `dispose()` that leaves the cache reusable (React StrictMode remounts).
- **Preview pitch.** Web Audio's `playbackRate` shifts pitch; FFmpeg's `atempo` doesn't. Preview of a sped-up video layer is therefore higher-pitched than the export. This is documented, and A2.5 uses rate 1.
- **Test clips use 4:2:0.** `clip-with-audio.mp4` and `clip-silent.mp4` get `-pix_fmt yuv420p` (spec §7 omits it, so libx264 picks 4:4:4, which WebCodecs on macOS can't decode). Audio is unchanged.
- **e2e hook.** The acceptance checks need real exports through the real webview. Debug builds read `LCS_E2E=<script.json>`; release builds never do, and production bundles don't include the frontend half.

```ts
import type { MotionPathDef, MotionPathPoint } from '../types';
import { getEasing } from './easing';

export interface PathResult {
  x: number;
  y: number;
  angle: number; // radians, tangent direction
}

/** Samples per segment in the arc-length table. Fixed, so output is deterministic. */
const ARC_SAMPLES = 48;

/**
 * Where a layer is on its motion path at `frameInLayer`: linear progress
 * through the layer's life, shaped by the path's easing, then placed on the
 * path by its timing mode.
 */
export function motionPathAt(
  path: MotionPathDef,
  frameInLayer: number,
  layerDuration: number,
): PathResult {
  const linear = layerDuration > 0 ? frameInLayer / layerDuration : 0;
  const t = getEasing(path.easing ?? 'linear', path.easingParams)(linear);
  return evaluateMotionPath(path, t);
}

/**
 * Evaluate a position along a motion path at progress t (already eased).
 * Each segment between consecutive points is a cubic bezier or a line.
 * Looping paths wrap t; open paths extrapolate along the end tangent when an
 * overshooting easing pushes t outside 0–1, so the overshoot stays visible.
 */
export function evaluateMotionPath(path: MotionPathDef, t: number): PathResult {
  const pts = path.points;
  if (pts.length === 0) return { x: 0, y: 0, angle: 0 };
  if (pts.length === 1) return { x: pts[0].x, y: pts[0].y, angle: 0 };
  if (!Number.isFinite(t)) t = 0;

  if (path.loop) {
    t = t % 1;
    if (t < 0) t += 1;
  }

  return path.timing === 'constant-speed'
    ? evaluateConstantSpeed(pts, t)
    : evaluatePerSegment(pts, t);
}

/** Every segment gets an equal share of t — the original behaviour. */
function evaluatePerSegment(pts: MotionPathPoint[], t: number): PathResult {
  const segments = pts.length - 1;
  if (t < 0) {
    return extrapolate(pts, 0, 0, t * segments * arcTable(pts).lengths[0]);
  }
  if (t > 1) {
    const last = segments - 1;
    return extrapolate(pts, last, 1, (t - 1) * segments * arcTable(pts).lengths[last]);
  }
  const segProgress = t * segments;
  const segIndex = Math.min(Math.floor(segProgress), segments - 1);
  return pointOnSegment(pts, segIndex, segProgress - segIndex);
}

/** t is a share of the path's whole length. */
function evaluateConstantSpeed(pts: MotionPathPoint[], t: number): PathResult {
  const table = arcTable(pts);
  if (table.total === 0) return pointOnSegment(pts, 0, 0);

  const d = t * table.total;
  if (d <= 0) {
    const first = table.lengths.findIndex((l) => l > 0);
    return d < 0 ? extrapolate(pts, first, 0, d) : pointOnSegment(pts, first, 0);
  }
  if (d >= table.total) {
    const last = lastIndexWhere(table.lengths, (l) => l > 0);
    return d > table.total ? extrapolate(pts, last, 1, d - table.total) : pointOnSegment(pts, last, 1);
  }

  // The segment holding distance d. A zero-length segment never matches, as
  // d >= its start + 0 always moves past it.
  let i = 0;
  while (i < pts.length - 2 && d >= table.starts[i] + table.lengths[i]) i++;

  // Invert the segment's cumulative samples: find the interval holding d,
  // then interpolate the curve parameter within it.
  const local = d - table.starts[i];
  const cum = table.cumulative[i];
  let lo = 0;
  let hi = ARC_SAMPLES;
  while (hi - lo > 1) {
    const mid = (lo + hi) >> 1;
    if (cum[mid] <= local) lo = mid;
    else hi = mid;
  }
  const span = cum[hi] - cum[lo];
  const frac = span > 0 ? (local - cum[lo]) / span : 0;
  return pointOnSegment(pts, i, (lo + frac) / ARC_SAMPLES);
}

function lastIndexWhere(values: number[], test: (v: number) => boolean): number {
  for (let i = values.length - 1; i >= 0; i--) if (test(values[i])) return i;
  return values.length - 1;
}

// ── Segment geometry ──────────────────────────────────

interface SegmentPoint {
  x: number;
  y: number;
  dx: number; // derivative with respect to the segment parameter
  dy: number;
}

/** Position and derivative on segment i (pts[i] → pts[i + 1]) at parameter u. */
function segmentAt(pts: MotionPathPoint[], i: number, u: number): SegmentPoint {
  const p0 = pts[i];
  const p1 = pts[i + 1];

  // If either point has control points, use cubic bezier
  const hasCP0 = p0.cpX !== undefined && p0.cpY !== undefined;
  const hasCP1 = p1.cpX !== undefined && p1.cpY !== undefined;

  if (hasCP0 || hasCP1) {
    // Cubic bezier: P0 → CP0 → CP1 → P1
    // If one CP missing, use midpoint as default
    const cp0x = hasCP0 ? p0.cpX! : (p0.x + p1.x) / 2;
    const cp0y = hasCP0 ? p0.cpY! : (p0.y + p1.y) / 2;
    const cp1x = hasCP1 ? p1.cpX! : (p0.x + p1.x) / 2;
    const cp1y = hasCP1 ? p1.cpY! : (p0.y + p1.y) / 2;
    return {
      x: cubicBezier(p0.x, cp0x, cp1x, p1.x, u),
      y: cubicBezier(p0.y, cp0y, cp1y, p1.y, u),
      dx: cubicBezierDeriv(p0.x, cp0x, cp1x, p1.x, u),
      dy: cubicBezierDeriv(p0.y, cp0y, cp1y, p1.y, u),
    };
  }

  // Linear interpolation
  return {
    x: p0.x + (p1.x - p0.x) * u,
    y: p0.y + (p1.y - p0.y) * u,
    dx: p1.x - p0.x,
    dy: p1.y - p0.y,
  };
}

function pointOnSegment(pts: MotionPathPoint[], i: number, u: number): PathResult {
  const s = segmentAt(pts, i, u);
  return { x: s.x, y: s.y, angle: Math.atan2(s.dy, s.dx) };
}

/**
 * Continue straight on from segment i at parameter u (0 = its start, 1 = its
 * end) for `distance` px along its tangent; negative goes backwards.
 */
function extrapolate(pts: MotionPathPoint[], i: number, u: number, distance: number): PathResult {
  const s = segmentAt(pts, i, u);
  let dx = s.dx;
  let dy = s.dy;
  if (Math.hypot(dx, dy) < 1e-9) {
    // A control point sitting on the end point leaves no derivative there;
    // the chord still points the right way.
    dx = pts[i + 1].x - pts[i].x;
    dy = pts[i + 1].y - pts[i].y;
  }
  const len = Math.hypot(dx, dy);
  if (len < 1e-9) return { x: s.x, y: s.y, angle: 0 };
  return {
    x: s.x + (dx / len) * distance,
    y: s.y + (dy / len) * distance,
    angle: Math.atan2(dy, dx),
  };
}

function cubicBezier(p0: number, p1: number, p2: number, p3: number, t: number): number {
  const mt = 1 - t;
  return mt * mt * mt * p0 + 3 * mt * mt * t * p1 + 3 * mt * t * t * p2 + t * t * t * p3;
}

function cubicBezierDeriv(p0: number, p1: number, p2: number, p3: number, t: number): number {
  const mt = 1 - t;
  return 3 * mt * mt * (p1 - p0) + 6 * mt * t * (p2 - p1) + 3 * t * t * (p3 - p2);
}

// ── Arc length ────────────────────────────────────────

interface ArcTable {
  /** cumulative[i][k]: distance from segment i's start to its sample k (k = 0…ARC_SAMPLES). */
  cumulative: Float64Array[];
  lengths: number[];
  /** Distance from the path's start to each segment's start. */
  starts: number[];
  total: number;
}

/**
 * Keyed by the points array. Store updates replace the array rather than
 * mutating it, so a changed path always gets a fresh table.
 */
const arcTables = new WeakMap<MotionPathPoint[], ArcTable>();

function arcTable(pts: MotionPathPoint[]): ArcTable {
  let table = arcTables.get(pts);
  if (!table) {
    table = buildArcTable(pts);
    arcTables.set(pts, table);
  }
  return table;
}

function buildArcTable(pts: MotionPathPoint[]): ArcTable {
  const cumulative: Float64Array[] = [];
  const lengths: number[] = [];
  const starts: number[] = [];
  let total = 0;
  for (let i = 0; i < pts.length - 1; i++) {
    const cum = new Float64Array(ARC_SAMPLES + 1);
    let prev = segmentAt(pts, i, 0);
    for (let k = 1; k <= ARC_SAMPLES; k++) {
      const cur = segmentAt(pts, i, k / ARC_SAMPLES);
      cum[k] = cum[k - 1] + Math.hypot(cur.x - prev.x, cur.y - prev.y);
      prev = cur;
    }
    starts.push(total);
    lengths.push(cum[ARC_SAMPLES]);
    cumulative.push(cum);
    total += cum[ARC_SAMPLES];
  }
  return { cumulative, lengths, starts, total };
}
```

```rust
/// Up to three decimals with trailing zeros dropped: 2.5 → "2.5", 3.0 → "3".
fn num(x: f64) -> String {
    let s = format!("{x:.3}");
    let s = s.trim_end_matches('0').trim_end_matches('.');
    if s == "-0" { "0".to_string() } else { s.to_string() }
}

/// `-ss -t -i` for one track. Reads `duration × rate` seconds of source, so
/// that after `atempo` the sound lasts `duration` seconds.
fn audio_input_args(track: &AudioTrackSpec) -> Vec<String> {
    vec![
        "-ss".into(), num(track.start_time_secs),
        "-t".into(), num(track.duration_secs * track.rate()),
        "-i".into(), track.path.clone(),
    ]
}

/// One `atempo` accepts 0.5–100, so rates outside that are chained.
fn atempo_chain(rate: f64) -> Vec<String> {
    let mut filters = Vec::new();
    let mut r = rate;
    while r < 0.5 {
        filters.push("atempo=0.5".to_string());
        r /= 0.5;
    }
    while r > 100.0 {
        filters.push("atempo=100".to_string());
        r /= 100.0;
    }
    if (r - 1.0).abs() > 1e-9 {
        filters.push(format!("atempo={}", num(r)));
    }
    filters
}

/// The audio `-filter_complex` graph. Each track (input i + 1) is resampled,
/// sped up or slowed down, levelled, faded and delayed to its place on the
/// timeline; then all are mixed without normalisation (which would turn
/// every track down), limited, and padded with silence so the video alone
/// decides the output length under `-shortest`.
pub fn build_audio_filter(tracks: &[AudioTrackSpec]) -> Option<String> {
    if tracks.is_empty() {
        return None;
    }
    let mut graph = String::new();
    for (i, track) in tracks.iter().enumerate() {
        let mut chain = vec!["aformat=sample_rates=48000:channel_layouts=stereo".to_string()];
        chain.extend(atempo_chain(track.rate()));
        chain.push(format!("volume={}", num(track.volume)));
        if track.fade_in_secs > 0.0 {
            chain.push(format!("afade=t=in:st=0:d={}", num(track.fade_in_secs)));
        }
        if track.fade_out_secs > 0.0 {
            let start = (track.duration_secs - track.fade_out_secs).max(0.0);
            chain.push(format!("afade=t=out:st={}:d={}", num(start), num(track.fade_out_secs)));
        }
        let delay_ms = (track.timeline_offset_secs * 1000.0).round().max(0.0) as u64;
        chain.push(format!("adelay=delays={delay_ms}:all=1"));
        graph.push_str(&format!("[{}:a]{}[a{i}];", i + 1, chain.join(",")));
    }
    for i in 0..tracks.len() {
        graph.push_str(&format!("[a{i}]"));
    }
    graph.push_str(&format!(
        "amix=inputs={}:duration=longest:normalize=0,alimiter=limit=0.95,apad[aout]",
        tracks.len()
    ));
    Some(graph)
}

/// The full FFmpeg command line for a render. GIF never carries sound.
pub fn build_ffmpeg_args(
    width: u32,
    height: u32,
    fps: u32,
    output_path: &str,
    audio_tracks: &[AudioTrackSpec],
    format: &str,
    quality: &str,
) -> Vec<String> {
    let tracks: &[AudioTrackSpec] = if format == "gif" { &[] } else { audio_tracks };

    let mut args: Vec<String> = vec![
        "-y".into(),
        "-hide_banner".into(),
        "-nostats".into(),
        "-loglevel".into(), "error".into(),
        "-f".into(), "rawvideo".into(),
        "-pix_fmt".into(), "rgba".into(),
        "-s".into(), format!("{width}x{height}"),
        "-r".into(), fps.to_string(),
        "-i".into(), "pipe:0".into(),
    ];

    for track in tracks {
        args.extend(audio_input_args(track));
    }

    // Format-specific video encoding
    match format {
        "webm" => {
            args.extend(["-c:v".into(), "libvpx-vp9".into(), "-pix_fmt".into(), "yuv420p".into()]);
            if quality == "lossless" {
                args.extend(["-lossless".into(), "1".into()]);
            } else {
                let crf = match quality {
                    "low" => "40",
                    "high" => "24",
                    _ => "31", // medium
                };
                args.extend(["-b:v".into(), "0".into(), "-crf".into(), crf.into()]);
            }
            args.extend(["-row-mt".into(), "1".into()]);
        }
        "gif" => {
            // Single-pass GIF with inline palette generation
            let vf = format!(
                "fps={fps},split[s0][s1];[s0]palettegen=max_colors={colors}[p];[s1][p]paletteuse=dither={dither}",
                fps = fps,
                colors = match quality {
                    "low" => 64,
                    "medium" => 128,
                    "lossless" => 256,
                    _ => 256, // high
                },
                dither = if quality == "lossless" { "none" } else { "sierra2_4a" },
            );
            args.extend(["-vf".into(), vf, "-loop".into(), "0".into()]);
        }
        "mov" => {
            let profile = match quality {
                "low" => "0",      // proxy
                "medium" => "1",   // lt
                "high" => "2",     // hq
                "lossless" => "4", // 4444
                _ => "2",
            };
            args.extend([
                "-c:v".into(), "prores_ks".into(),
                "-profile:v".into(), profile.into(),
                "-pix_fmt".into(), "yuva444p10le".into(),
                "-vendor".into(), "apl0".into(),
            ]);
        }
        _ => {
            // MP4 (H.264) — default
            let (crf, preset) = match quality {
                "low" => ("32", "fast"),
                "high" => ("18", "medium"),
                "lossless" => ("0", "veryslow"),
                _ => ("23", "medium"), // medium
            };
            args.extend([
                "-c:v".into(), "libx264".into(),
                "-pix_fmt".into(), "yuv420p".into(),
                "-preset".into(), preset.into(),
                "-crf".into(), crf.into(),
                "-movflags".into(), "+faststart".into(),
            ]);
        }
    }

    match build_audio_filter(tracks) {
        None => args.push("-an".into()),
        Some(graph) => {
            let (codec, bitrate): (&str, Option<&str>) = match format {
                "webm" => ("libopus", Some("128k")),
                "mov" => ("pcm_s16le", None),
                _ => ("aac", Some("192k")),
            };
            args.extend([
                "-filter_complex".into(), graph,
```

```rust
pub struct FfmpegProcess {
    child: Child,
    stdin: Option<ChildStdin>,
    /// Drains stderr and yields its last lines once FFmpeg closes it.
    stderr: Option<JoinHandle<String>>,
}

impl FfmpegProcess {
    pub fn write_frame(&mut self, data: &[u8]) -> Result<(), String> {
        let stdin = self
            .stdin
            .as_mut()
            .ok_or("FFmpeg stdin already closed")?;
        if let Err(e) = stdin.write_all(data) {
            // FFmpeg has usually exited already — a bad filter graph or an
            // unreadable input — and its stderr says why.
            drop(self.stdin.take());
            let _ = self.child.wait();
            return Err(with_stderr(format!("Failed to write frame to FFmpeg: {e}"), self.stderr_tail()));
        }
        Ok(())
    }

    pub fn finish(mut self) -> Result<(), String> {
        // Drop stdin to signal EOF to FFmpeg
        drop(self.stdin.take());

        let status = self
            .child
            .wait()
            .map_err(|e| format!("Failed to wait for FFmpeg: {e}"))?;
        let stderr = self.stderr_tail();

        if status.success() {
            Ok(())
        } else {
            Err(with_stderr(format!("FFmpeg exited with status: {status}"), stderr))
        }
    }

    pub fn kill(&mut self) -> Result<(), String> {
        drop(self.stdin.take());
        self.child
            .kill()
            .map_err(|e| format!("Failed to kill FFmpeg: {e}"))
    }

    /// FFmpeg's last stderr lines. Call only after it has exited.
    fn stderr_tail(&mut self) -> String {
        self.stderr.take().and_then(|h| h.join().ok()).unwrap_or_default()
    }
}

/// Read stderr on a thread so a chatty FFmpeg can never fill the pipe and
/// stall, keeping only the last lines.
fn read_stderr(stderr: ChildStderr) -> JoinHandle<String> {
    std::thread::spawn(move || {
        let mut tail: VecDeque<String> = VecDeque::new();
        for line in BufReader::new(stderr).lines().map_while(Result::ok) {
            if tail.len() == STDERR_TAIL_LINES {
                tail.pop_front();
            }
            tail.push_back(line);
        }
        Vec::from(tail).join("\n")
    })
}

fn with_stderr(message: String, stderr: String) -> String {
    let stderr = stderr.trim();
    if stderr.is_empty() { message } else { format!("{message}\n{stderr}") }
}
```

```ts
import { readFile } from '@tauri-apps/plugin-fs';
import { resolveAssetPath } from './asset-manager';

/** Files above this are still read whole, with a warning: they stay in memory while in use. */
const LARGE_FILE_BYTES = 500 * 1024 * 1024;

function isUrl(src: string): boolean {
  return /^(https?|blob|data):/.test(src);
}

/**
 * Read a media file into a Blob. Project assets and absolute paths go through
 * plugin-fs, because a filesystem path is not a URL the webview can load;
 * http(s), blob and data URLs are fetched.
 */
export async function loadMediaBlob(src: string, projectDir: string | null): Promise<Blob> {
  if (isUrl(src)) {
    const response = await fetch(src);
    if (!response.ok) throw new Error(`HTTP ${response.status} for ${src}`);
    return response.blob();
  }
  const bytes = await readFile(await resolveAssetPath(src, projectDir));
  if (bytes.byteLength > LARGE_FILE_BYTES) {
    console.warn(`${src} is ${Math.round(bytes.byteLength / 1048576)} MB and is held in memory while in use`);
  }
  return new Blob([bytes]);
}

/** Media read for one project folder, one read per source; concurrent requests share it. */
export class MediaBlobCache {
  private blobs = new Map<string, Promise<Blob>>();

  constructor(private readonly projectDir: string | null) {}

  get(src: string): Promise<Blob> {
    let blob = this.blobs.get(src);
    if (!blob) {
      const loading = loadMediaBlob(src, this.projectDir);
      // A failed read isn't kept, so a fixed file can be tried again.
      loading.catch(() => {
        if (this.blobs.get(src) === loading) this.blobs.delete(src);
      });
      this.blobs.set(src, loading);
      blob = loading;
    }
    return blob;
  }

  clear(): void {
    this.blobs.clear();
  }
}
```

```ts
import { ALL_FORMATS, BlobSource, Input } from 'mediabunny';
import type { AudioLayerData, AudioTrackSpec, Composition, VideoLayerData } from '../types';
import { resolveAssetPath } from './asset-manager';
import { loadMediaBlob } from './media-bytes';

/** Where and how one layer's sound plays. Shared by export and preview, so they agree. */
export interface AudioTiming {
  timelineOffsetSecs: number; // where it starts in the output
  sourceStartSecs: number;    // where it starts reading in the source
  durationSecs: number;       // how long it lasts in the output
  volume: number;
  fadeInSecs: number;
  fadeOutSecs: number;
  playbackRate: number;
}

export interface AudibleLayer {
  layer: AudioLayerData | VideoLayerData;
  timing: AudioTiming;
}

/**
 * Timing for one layer of a scene that starts at `sceneStartFrame`. A layer
 * plays for its frame range, cut at the scene's end as its visuals are, and
 * no further than `endTime` when that is after `startTime`. Audio layers
 * carry volume and fades; video layers carry speed.
 */
export function audioTiming(
  layer: AudioLayerData | VideoLayerData,
  sceneStartFrame: number,
  sceneDurationFrames: number,
  fps: number,
): AudioTiming {
  const isAudio = layer.type === 'audio';
  const rate = !isAudio && layer.playbackRate > 0 ? layer.playbackRate : 1;
  const endFrame = Math.min(layer.endFrame, sceneDurationFrames);
  let durationSecs = (endFrame - layer.startFrame) / fps;
  if (layer.endTime > layer.startTime) {
    durationSecs = Math.min(durationSecs, (layer.endTime - layer.startTime) / rate);
  }
  return {
    timelineOffsetSecs: (sceneStartFrame + layer.startFrame) / fps,
    sourceStartSecs: layer.startTime,
    durationSecs: Math.max(0, durationSecs),
    volume: isAudio ? layer.volume : 1,
    fadeInSecs: isAudio ? layer.fadeInFrames / fps : 0,
    fadeOutSecs: isAudio ? layer.fadeOutFrames / fps : 0,
    playbackRate: rate,
  };
}

/**
 * Every layer that should be heard, with its timing: visible audio layers
 * and visible unmuted video layers. Scenes play back to back (transitions
 * happen inside the outgoing scene), so each starts where the last ended.
 * Whether a video file actually has sound needs the file; see buildAudioTracks.
 */
export function collectAudibleLayers(composition: Composition): AudibleLayer[] {
  const { fps } = composition.output;
  const audible: AudibleLayer[] = [];
  let sceneStart = 0;
  for (const scene of composition.scenes) {
    for (const layer of scene.layers) {
      if (!layer.visible) continue;
      if (layer.type !== 'audio' && !(layer.type === 'video' && !layer.muted)) continue;
      const timing = audioTiming(layer, sceneStart, scene.durationFrames, fps);
      if (timing.durationSecs > 0) audible.push({ layer, timing });
    }
    sceneStart += scene.durationFrames;
  }
  return audible;
}

/** Whether a media file has an audio track, read from its container (no decoding). */
export async function hasAudioTrack(blob: Blob): Promise<boolean> {
  const input = new Input({ source: new BlobSource(blob), formats: ALL_FORMATS });
  try {
    return (await input.getPrimaryAudioTrack()) !== null;
  } finally {
    input.dispose();
  }
}

/**
 * The FFmpeg audio tracks for an export. Video layers whose file has no audio
 * stream are dropped silently, because FFmpeg fails on a missing stream.
 */
export async function buildAudioTracks(
  composition: Composition,
  projectDir: string | null,
  probe: (src: string) => Promise<boolean> = async (src) => hasAudioTrack(await loadMediaBlob(src, projectDir)),
): Promise<AudioTrackSpec[]> {
  const probed = new Map<string, Promise<boolean>>();
  const hasSound = (src: string) => {
    let result = probed.get(src);
    if (!result) {
      result = probe(src).catch((err) => {
        console.warn(`Could not read ${src}; leaving its sound out:`, err);
        return false;
      });
      probed.set(src, result);
    }
    return result;
  };

  const tracks: AudioTrackSpec[] = [];
  for (const { layer, timing } of collectAudibleLayers(composition)) {
    if (layer.type === 'video' && !(await hasSound(layer.src))) continue;
    tracks.push({
      path: await resolveAssetPath(layer.src, projectDir),
      startTimeSecs: timing.sourceStartSecs,
      durationSecs: timing.durationSecs,
      volume: timing.volume,
      timelineOffsetSecs: timing.timelineOffsetSecs,
      fadeInSecs: timing.fadeInSecs,
      fadeOutSecs: timing.fadeOutSecs,
      playbackRate: timing.playbackRate,
    });
  }
  return tracks;
}
```

```rust
//! Scripted end-to-end runs for the acceptance checks in `scripts/e2e/`.
//!
//! Debug builds only. Started with `LCS_E2E=<script.json>`, the frontend asks
//! for the script on startup, runs its jobs in the real webview, hands back
//! the results, and the app quits. Release builds never read the variable.

use std::path::PathBuf;

use tauri::{AppHandle, Runtime};
use tauri_plugin_fs::FsExt;

fn script_path() -> Option<PathBuf> {
    if !cfg!(debug_assertions) {
        return None;
    }
    std::env::var_os("LCS_E2E").map(PathBuf::from)
}

/// The script's JSON, or None on a normal run. Grants the frontend access to
/// the script's folder, which holds the jobs' projects and outputs.
#[tauri::command]
pub fn e2e_script<R: Runtime>(app: AppHandle<R>) -> Result<Option<String>, String> {
    let Some(path) = script_path() else { return Ok(None) };
    let dir = path.parent().ok_or("the e2e script has no folder")?;
    app.fs_scope()
        .allow_directory(dir, true)
        .map_err(|e| format!("could not allow {}: {e}", dir.display()))?;
    std::fs::read_to_string(&path)
        .map(Some)
        .map_err(|e| format!("{}: {e}", path.display()))
}

/// Write the results beside the script as `<name>.result.json`, then quit.
#[tauri::command]
pub fn e2e_finish<R: Runtime>(app: AppHandle<R>, result: String) -> Result<(), String> {
    let path = script_path().ok_or("not an e2e run")?;
    std::fs::write(path.with_extension("result.json"), result).map_err(|e| e.to_string())?;
    app.exit(0);
    Ok(())
}
```

```ts
/**
 * Scripted acceptance runs for scripts/e2e/. Debug builds only: the app is
 * started with LCS_E2E=<script.json> (see src-tauri/src/e2e.rs), runs the
 * script's jobs here in the real webview, hands the results back and quits.
 * App.tsx loads this module behind import.meta.env.DEV, so production
 * bundles never include it.
 */
import { invoke } from '@tauri-apps/api/core';
import type { ExportFormat, QualityPreset } from '../types';
import { renderComposition } from '../renderer/capture';
import { loadProjectFromPath, removeFromRecent } from './project-io';

export type E2eJob =
  | { kind: 'render'; project: string; format: ExportFormat; output: string; quality?: QualityPreset };

export interface E2eResult {
  job: E2eJob;
  ok: boolean;
  ms: number;
  error?: string;
  data?: unknown;
}

let started = false;

async function openProject(path: string) {
  const project = await loadProjectFromPath(path);
  removeFromRecent(project.path); // keep test projects out of the recent list
  return project;
}

async function runJob(job: E2eJob): Promise<unknown> {
  switch (job.kind) {
    case 'render': {
      const { path, composition } = await openProject(job.project);
      await renderComposition(composition, job.output, undefined, job.format, job.quality ?? 'medium', path);
      return undefined;
    }
  }
}

export async function runE2eIfRequested(): Promise<void> {
  // StrictMode mounts twice in development; run once. Outside Tauri there's no script.
  if (started || !('__TAURI_INTERNALS__' in window)) return;
  started = true;
  const script = await invoke<string | null>('e2e_script');
  if (!script) return;

  const { jobs } = JSON.parse(script) as { jobs: E2eJob[] };
  const results: E2eResult[] = [];
  for (const job of jobs) {
    const start = performance.now();
    try {
      const data = await runJob(job);
      results.push({ job, ok: true, ms: performance.now() - start, data });
    } catch (err) {
      results.push({ job, ok: false, ms: performance.now() - start, error: String(err) });
    }
  }
  await invoke('e2e_finish', { result: JSON.stringify(results, null, 2) });
}
```

```js
  const script = join(dir, 'script.json');

  writeFileSync(script, JSON.stringify({ jobs }, null, 2));

/** ffprobe's streams: [{ codec_type, codec_name, duration }]. */
export function streams(file) {
  const out = execFileSync('ffprobe', ['-v', 'error', '-show_entries', 'stream=codec_type,codec_name,duration', '-of', 'json', file]);
  return JSON.parse(out).streams.map((s) => ({ ...s, duration: Number(s.duration) }));
}

/** Silent stretches [{ start, end }] of a file's audio, optionally through a narrow band filter. */
export function silences(file, { band, noise = band ? '-40dB' : '-50dB' } = {}) {
  const filters = [];
  if (band) filters.push(`bandpass=f=${band}:width_type=q:w=8`, `bandpass=f=${band}:width_type=q:w=8`);
  filters.push(`silencedetect=n=${noise}:d=0.1`);
  const { stderr } = spawnSync('ffmpeg', ['-hide_banner', '-nostats', '-i', file, '-af', filters.join(','), '-f', 'null', '-'], { encoding: 'utf8' });
  const found = [];
  let start = null;
  for (const m of stderr.matchAll(/silence_(start|end): ([\d.]+)/g)) {
    if (m[1] === 'start') start = Number(m[2]);
    else { found.push({ start, end: Number(m[2]) }); start = null; }
  }
  if (start !== null) found.push({ start, end: Infinity });
  return found;
}

/** Whether a tone in `band` Hz is audible at second `t`. */
export const audibleAt = (file, band, t) => !silences(file, { band }).some((g) => g.start <= t && t <= g.end);

async function imageData(file) {

  const ctx = canvas.getContext('2d');
  ctx.drawImage(img, 0, 0);
  return ctx.getImageData(0, 0, img.width, img.height);
}

/** [r, g, b, a] of one pixel of an image file. */
export async function pixel(file, x = W / 2, y = H / 2) {
  const { data, width } = await imageData(file);
  const i = (Math.round(y) * width + Math.round(x)) * 4;
  return [data[i], data[i + 1], data[i + 2], data[i + 3]];
}

/** Every decoded pixel of an image, for exact comparison. */
export async function pngPixels(file) {
  return Buffer.from((await imageData(file)).data);
}

/**

 * luma is 16 + 7·id in limited range, which decodes to grey ≈ 7·id·255/219.
 */
export const frameId = (grey) => Math.round((grey * 219) / 255 / 7);

/** Print PASS/FAIL rows and set the exit code. */

  for (const r of rows) console.log(`${r.ok ? 'PASS' : 'FAIL'}  ${r.id}  ${r.detail ?? ''}`);
  const failed = rows.filter((r) => !r.ok).length;
  console.log(failed ? `${failed} check(s) failed` : `all ${rows.length} checks passed`);
  process.exitCode = failed ? 1 : 0;
}
```

```ts
/**
 * The transition playing at this frame of a scene, if any. Transitions run
 * over the outgoing scene's last frames and show the incoming scene frozen
 * at its frame 0.
 */
export function transitionAt(
  composition: Composition,
  sceneIndex: number,
  frameInScene: number,
): { incoming: Scene; progress: number } | null {
  const scene = composition.scenes[sceneIndex];
  const incoming = composition.scenes[sceneIndex + 1];
  const duration = scene.transitionDurationFrames || 0;
  const start = scene.durationFrames - duration;
  if (!incoming || scene.transition === 'none' || scene.transition === 'cut' || duration <= 0 || frameInScene < start) {
    return null;
  }
  return { incoming, progress: (frameInScene - start) / duration };
}
```

```ts
import type { Composition, Layer, VideoLayerData } from '../types';
import { resolveFrame, transitionAt } from './compositor';

/** Pulls a clamped endTime back far enough that the held frame is the one before endTime. */
const END_EPSILON = 1e-3;
/** Nudges every lookup into its frame, so float error never lands on the frame before. */
const LOOKUP_EPSILON = 1e-4;

/**
 * The source time a video layer shows at `frameInLayer`:
 * startTime + frameInLayer / fps × playbackRate. With an endTime after
 * startTime the clip holds its last frame before endTime from then on.
 */
export function sourceTimeFor(
  layer: Pick<VideoLayerData, 'startTime' | 'endTime' | 'playbackRate'>,
  frameInLayer: number,
  fps: number,
): number {
  const rate = layer.playbackRate > 0 ? layer.playbackRate : 1;
  let t = layer.startTime + (frameInLayer / fps) * rate;
  if (layer.endTime > layer.startTime) {
    t = Math.min(Math.max(t, layer.startTime), layer.endTime - END_EPSILON);
  }
  return t + LOOKUP_EPSILON;
}

/** One video frame a composition frame draws. */
export interface VideoDraw {
  layerId: string;
  src: string;
  sourceTime: number;
}

function addActiveVideo(layers: Layer[], frameInScene: number, fps: number, draws: VideoDraw[]): void {
  for (const layer of layers) {
    if (layer.type !== 'video' || !layer.visible) continue;
    if (frameInScene < layer.startFrame || frameInScene >= layer.endFrame) continue;
    draws.push({
      layerId: layer.id,
      src: layer.src,
      sourceTime: sourceTimeFor(layer, frameInScene - layer.startFrame, fps),
    });
  }
}

/**
 * The video frames drawCompositionFrame draws at `globalFrame`, mirroring it:
 * the current scene's visible, active video layers, plus — during a
 * transition — the incoming scene's, frozen at its frame 0. Echo stamps reuse
 * the current frame, so they add nothing.
 */
export function collectVideoDraws(composition: Composition, globalFrame: number): VideoDraw[] {
  const { sceneIndex, frameInScene } = resolveFrame(composition, globalFrame);
  if (sceneIndex < 0) return [];
  const { fps } = composition.output;
  const draws: VideoDraw[] = [];
  addActiveVideo(composition.scenes[sceneIndex].layers, frameInScene, fps, draws);
  const transition = transitionAt(composition, sceneIndex, frameInScene);
  if (transition) addActiveVideo(transition.incoming.layers, 0, fps, draws);
  return draws;
}
```

```ts
import type { VideoLayerData, ResolvedTransform } from '../types';
import { fitRect } from './fit';

/** A decoded video frame, ready to draw. */
export type VideoFrameImage = HTMLCanvasElement | OffscreenCanvas;

/** Video frames decoded ahead of a synchronous draw, by layer id. */
export interface PreparedVideoFrames {
  get(layerId: string): VideoFrameImage | undefined;
}

/**
 * Draw the frame prepared for this layer, cover-fitted and clipped to the
 * layer box as image layers are. With nothing prepared — the clip is still
 * decoding (preview only; export always prepares first) or can't be decoded —
 * the layer draws nothing, and whatever is underneath shows.
 */
export function drawVideoLayer(
  ctx: CanvasRenderingContext2D,
  layer: VideoLayerData,
  resolved: ResolvedTransform,
  frames: PreparedVideoFrames,
): void {
  const frame = frames.get(layer.id);
  if (!frame) return;

  const { width: dw, height: dh } = resolved;
  if (frame.width === 0 || frame.height === 0 || dw <= 0 || dh <= 0) return;

  const r = fitRect('cover', frame.width, frame.height, dw, dh);
  ctx.beginPath();
  ctx.rect(0, 0, dw, dh);
  ctx.clip();
  ctx.drawImage(frame, r.x, r.y, r.w, r.h);
}
```

```ts
/*
 * Decoded-frame cache for video layers.
 *
 * Adapted from OpenCut Classic — apps/web/src/services/video-cache/service.ts
 * at commit cf5e79e9 (https://github.com/opencut-app/opencut-classic).
 * Copyright 2025-2026 OpenCut. MIT licence; the full notice is in
 * THIRD_PARTY_NOTICES.md.
 *
 * Kept from OpenCut: reuse the current frame when it covers the time; decode
 * forward for jumps under two seconds, otherwise seek; prefetch one frame
 * ahead; one promise chain per key so requests never race; a generation
 * counter so scrubbing drops stale requests.
 *
 * Changed for lc-studio: state is keyed by layer id rather than by file, so
 * two layers playing one file at different offsets don't fight over a decoder
 * (the bytes are shared through the loader); lookups have no tolerance, so
 * export gets the exact frame; times are clamped to the track, so a clip
 * shorter than its layer holds its last frame; a superseded request resolves
 * to nothing rather than the current frame; files that can't be opened are
 * remembered instead of retried; the decoder is injectable for tests; and
 * dispose() leaves the cache usable.
 */
import { ALL_FORMATS, BlobSource, CanvasSink, Input } from 'mediabunny';
import type { Composition } from '../types';
import type { PreparedVideoFrames, VideoFrameImage } from './draw-video';
import { collectVideoDraws, type VideoDraw } from './video-time';

/** A decoded frame and the source span it covers, in seconds. */
export interface DecodedFrame {
  canvas: VideoFrameImage;
  timestamp: number;
  duration: number;
}

/** What the cache needs from a decoder: mediabunny's CanvasSink, narrowed. */
export interface FrameSink {
  /** Frames in presentation order, starting with the one shown at `start`. */
  frames(start: number): AsyncGenerator<DecodedFrame, void, unknown>;
  /** The first frame's timestamp and the end of the last frame. */
  readonly startTime: number;
  readonly endTime: number;
  dispose(): void;
}

/** Opens a file for decoding, or throws with the reason it can't be. */
export type OpenFrameSink = (blob: Blob) => Promise<FrameSink>;

/** Forward jumps shorter than this decode on from the current position; longer ones seek. */
const FORWARD_DECODE_SECS = 2;
/** Times past the track's end are pulled back this far, onto its last frame. */
const TRACK_END_EPSILON = 1e-3;

/** Open a file's primary video track with mediabunny (WebCodecs). */
export const openMediabunnySink: OpenFrameSink = async (blob) => {
  if (typeof VideoDecoder === 'undefined') {
    throw new Error('this webview has no WebCodecs VideoDecoder');
  }
  const input = new Input({ source: new BlobSource(blob), formats: ALL_FORMATS });
  try {
    const track = await input.getPrimaryVideoTrack();
    if (!track) throw new Error('the file has no video track');
    if (!(await track.canDecode())) {
      throw new Error(`its ${track.codec ?? 'unknown'} video can't be decoded by this webview`);
    }
    const sink = new CanvasSink(track, { poolSize: 3 });
    const startTime = await track.getFirstTimestamp();
    const endTime = await track.computeDuration();
    return {
      startTime,
      endTime,
      frames: (start) => sink.canvases(start),
      dispose: () => input.dispose(),
    };
  } catch (error) {
    input.dispose();
    throw error;
  }
};

interface LayerDecoder {
  src: string;
  sink: FrameSink;
  iterator: AsyncGenerator<DecodedFrame, void, unknown> | null;
  currentFrame: DecodedFrame | null;
  nextFrame: DecodedFrame | null;
  lastTime: number;
  prefetching: boolean;
  prefetchPromise: Promise<void> | null;
}

function isFrameValid(frame: DecodedFrame, time: number): boolean {
  return time >= frame.timestamp && time < frame.timestamp + frame.duration;
}

export class VideoFrameCache implements PreparedVideoFrames {
  private decoders = new Map<string, LayerDecoder>();
  private opening = new Map<string, Promise<LayerDecoder | null>>();
  private frameChain = new Map<string, Promise<unknown>>();
  private generations = new Map<string, number>();
  private prepared = new Map<string, DecodedFrame>();
  private failed = new Map<string, string>();
  /** Bumped by dispose(), so decoders that finish opening afterwards are closed, not kept. */
  private epoch = 0;

  constructor(
    private readonly loadBlob: (src: string) => Promise<Blob>,
    private readonly openSink: OpenFrameSink = openMediabunnySink,
  ) {}

  get(layerId: string): VideoFrameImage | undefined {
    return this.prepared.get(layerId)?.canvas;
  }

  /** Files that couldn't be opened, with the reason. */
  failures(): ReadonlyMap<string, string> {
    return this.failed;
  }

  /**
   * Decode the frame each draw needs and keep it for get(). Resolves true when
   * any layer's prepared frame changed; preview redraws on that.
   */
  async prepare(draws: VideoDraw[]): Promise<boolean> {
    const changed = await Promise.all(draws.map(async ({ layerId, src, sourceTime }) => {
      const frame = await this.getFrameAt(layerId, src, sourceTime);
      if (frame === undefined) return false; // superseded by a newer request
      if (frame === null) return this.prepared.delete(layerId);
      const before = this.prepared.get(layerId);
      this.prepared.set(layerId, frame);
      return before?.canvas !== frame.canvas || before.timestamp !== frame.timestamp;
    }));
    return changed.includes(true);
  }

  /** Close the decoders of layers not in `layerIds`. */
  retain(layerIds: ReadonlySet<string>): void {
    for (const id of [...this.decoders.keys()]) if (!layerIds.has(id)) this.clearLayer(id);
    for (const id of [...this.prepared.keys()]) if (!layerIds.has(id)) this.prepared.delete(id);
  }

  /** Close every decoder and forget everything. The cache can be used again afterwards. */
  dispose(): void {
    this.epoch++;
    for (const id of [...this.decoders.keys()]) this.clearLayer(id);
    this.opening.clear();
    this.prepared.clear();
    this.failed.clear();
  }

  /** The frame for `time`; null when there is none, undefined when a newer request superseded this one. */
  private async getFrameAt(layerId: string, src: string, time: number): Promise<DecodedFrame | null | undefined> {
    const decoder = await this.decoderFor(layerId, src);
    if (!decoder) return null;
    const t = Math.min(Math.max(time, decoder.sink.startTime), decoder.sink.endTime - TRACK_END_EPSILON);

    const generation = (this.generations.get(layerId) ?? 0) + 1;
    this.generations.set(layerId, generation);

    const previous = this.frameChain.get(layerId) ?? Promise.resolve();
    const current = previous.then(() => {
      if (this.generations.get(layerId) !== generation) return undefined;
      return this.resolveFrame(decoder, t);
    });
    this.frameChain.set(layerId, current.catch(() => {}));
    return current;
  }

  private async decoderFor(layerId: string, src: string): Promise<LayerDecoder | null> {
    const existing = this.decoders.get(layerId);
    if (existing?.src === src) return existing;
    if (existing) this.clearLayer(layerId); // the layer now plays another file
    if (this.failed.has(src)) return null;

    const key = `${layerId}\u0000${src}`;
    let opening = this.opening.get(key);
    if (!opening) {
      const epoch = this.epoch;
      opening = (async () => {
        const decoder = await this.openDecoder(src);
        this.opening.delete(key);
        if (!decoder) return null;
        const current = this.decoders.get(layerId);
        if (epoch !== this.epoch || current) {
          decoder.sink.dispose();
          return epoch === this.epoch && current?.src === src ? current : null;
        }
        this.decoders.set(layerId, decoder);
        return decoder;
      })();
      this.opening.set(key, opening);
    }
    return opening;
  }

  private async openDecoder(src: string): Promise<LayerDecoder | null> {
    try {
      const sink = await this.openSink(await this.loadBlob(src));
      return {
        src, sink, iterator: null, currentFrame: null, nextFrame: null,
        lastTime: -1, prefetching: false, prefetchPromise: null,
      };
    } catch (error) {
      const reason = error instanceof Error ? error.message : String(error);
      if (!this.failed.has(src)) console.warn(`Video ${src} can't be drawn: ${reason}`);
      this.failed.set(src, reason);
      return null;
    }
  }

  private async resolveFrame(d: LayerDecoder, time: number): Promise<DecodedFrame | null> {
    if (d.nextFrame && d.nextFrame.timestamp <= time) {
      d.currentFrame = d.nextFrame;
      d.nextFrame = null;
      this.startPrefetch(d);
    }

    if (d.currentFrame && isFrameValid(d.currentFrame, time)) {
      this.startPrefetch(d);
      return d.currentFrame;
    }

    if (d.iterator && d.currentFrame && time >= d.lastTime && time < d.lastTime + FORWARD_DECODE_SECS) {
      const frame = await this.iterateToTime(d, time);
      if (frame) {
        this.startPrefetch(d);
        return frame;
      }
    }

    return this.seekToTime(d, time);
  }

  private async iterateToTime(d: LayerDecoder, time: number): Promise<DecodedFrame | null> {
    try {
      while (true) {
        // Let a running prefetch finish before touching the iterator.
        if (d.prefetching && d.prefetchPromise) await d.prefetchPromise;
        if (!d.iterator) return null;

        if (d.nextFrame) {
          // OpenCut took a frame up to 50 ms early here; export needs the exact one.
          if (d.nextFrame.timestamp > time) return null;
          d.currentFrame = d.nextFrame;
          d.nextFrame = null;
        } else {
          const { value, done } = await d.iterator.next();
          if (done || !value) return null;
          d.currentFrame = value;
        }

        const frame = d.currentFrame;
        d.lastTime = frame.timestamp;
        if (isFrameValid(frame, time)) return frame;
        if (frame.timestamp > time) return null; // decoded past it: seek instead
      }
    } catch (error) {
      console.warn('Video decode failed; seeking instead:', error);
      d.iterator = null;
      return null;
    }
  }

  private async seekToTime(d: LayerDecoder, time: number): Promise<DecodedFrame | null> {
    try {
      if (d.prefetching && d.prefetchPromise) await d.prefetchPromise;
      if (d.iterator) {
        await d.iterator.return();
        d.iterator = null;
      }
      d.nextFrame = null;
      d.iterator = d.sink.frames(time);
      d.lastTime = time;

      const { value } = await d.iterator.next();
      if (value) {
        d.currentFrame = value;
        this.startPrefetch(d);
        return value;
      }
    } catch (error) {
      console.warn('Video seek failed:', error);
      d.iterator = null;
    }
    return null;
  }

  private startPrefetch(d: LayerDecoder): void {
    if (d.prefetching || !d.iterator || d.nextFrame) return;
    d.prefetching = true;
    d.prefetchPromise = this.prefetchNextFrame(d);
  }

  private async prefetchNextFrame(d: LayerDecoder): Promise<void> {
    try {
      const { value, done } = await d.iterator!.next();
      if (!done && value) d.nextFrame = value;
    } catch (error) {
      console.warn('Video prefetch failed:', error);
      d.iterator = null;
    } finally {
      d.prefetching = false;
      d.prefetchPromise = null;
    }
  }

  private clearLayer(layerId: string): void {
    const decoder = this.decoders.get(layerId);
    if (decoder) {
      decoder.iterator?.return().catch(() => {});
      decoder.sink.dispose();
      this.decoders.delete(layerId);
    }
    this.frameChain.delete(layerId);
    this.generations.delete(layerId); // pending requests now see themselves superseded
  }
}

/** Decode every video frame drawCompositionFrame draws at `globalFrame`. */
export function prepareVideoFrames(
  composition: Composition,
  globalFrame: number,
  frames: VideoFrameCache,
): Promise<boolean> {
  return frames.prepare(collectVideoDraws(composition, globalFrame));
}
```

```ts
import type { Composition, Layer, VideoLayerData } from '../types';
import { openMediabunnySink } from '../renderer/video-frames';
import { loadMediaBlob } from './media-bytes';

/** Remembered per project folder and file: decodability doesn't change while the app runs. */
const decodable = new Map<string, Promise<boolean>>();

/** Whether this webview can decode a video file's frames. */
export function isVideoDecodable(src: string, projectDir: string | null): Promise<boolean> {
  const key = `${projectDir ?? ''}\u0000${src}`;
  let result = decodable.get(key);
  if (!result) {
    result = loadMediaBlob(src, projectDir)
      .then(openMediabunnySink)
      .then((sink) => { sink.dispose(); return true; }, () => false);
    decodable.set(key, result);
  }
  return result;
}

function visibleVideoLayers(composition: Composition): VideoLayerData[] {
  return composition.scenes
    .flatMap((s) => s.layers)
    .filter((l: Layer): l is VideoLayerData => l.type === 'video' && l.visible);
}

/** How many visible video layers will render as nothing because their file can't be decoded. */
export async function countUndecodableVideoLayers(composition: Composition, projectDir: string | null): Promise<number> {
  const ok = await Promise.all(visibleVideoLayers(composition).map((l) => isVideoDecodable(l.src, projectDir)));
  return ok.filter((d) => !d).length;
}

export function undecodableWarning(count: number): string | null {
  if (count === 0) return null;
  return count === 1
    ? "1 video layer can't be decoded; convert it to H.264 MP4"
    : `${count} video layers can't be decoded; convert them to H.264 MP4`;
}

/** Changes only when the visible video layers or their files do, so the probe isn't re-run on every edit. */
export function videoSourcesKey(composition: Composition): string {
  return visibleVideoLayers(composition).map((l) => `${l.id}:${l.src}`).join('\n');
}
```

```ts
import type { Composition } from '../types';
import { collectAudibleLayers, type AudioTiming } from '../lib/audio-tracks';

/** One scheduled sound. */
export interface Voice {
  source: AudioBufferSourceNode;
  gain: GainNode;
}

/**
 * Preview playback of audio layers and unmuted video layers' sound. Timing
 * comes from collectAudibleLayers, the helper the export uses, so preview
 * places, trims and fades every sound where the render does. One difference:
 * Web Audio's playbackRate shifts pitch, where FFmpeg's atempo keeps it.
 */
export class AudioEngine {
  private ctx: AudioContext | null = null;
  private buffers = new Map<string, Promise<AudioBuffer | null>>();
  private decoded = new Map<string, AudioBuffer>();
  private voices: Voice[] = [];

  constructor(
    private readonly loadBlob: (src: string) => Promise<Blob>,
    private readonly createContext: () => AudioContext = () => new AudioContext(),
  ) {}

  private context(): AudioContext {
    if (!this.ctx) this.ctx = this.createContext();
    return this.ctx;
  }

  /** Decode every audible file in every scene. Files without playable audio are skipped. */
  async preload(composition: Composition): Promise<void> {
    await Promise.all(collectAudibleLayers(composition).map(({ layer }) => this.load(layer.src)));
  }

  private load(src: string): Promise<AudioBuffer | null> {
    let buffer = this.buffers.get(src);
    if (!buffer) {
      buffer = this.loadBlob(src)
        .then((blob) => blob.arrayBuffer())
        .then((bytes) => this.context().decodeAudioData(bytes))
        .then((decoded) => {
          this.decoded.set(src, decoded);
          return decoded;
        })
        .catch((err) => {
          console.warn(`No playable audio in ${src}:`, err);
          return null;
        });
      this.buffers.set(src, buffer);
    }
    return buffer;
  }

  /** Resume audio from inside a user gesture; WebKit keeps it suspended until one. */
  unlock(): void {
    const ctx = this.context();
    if (ctx.state === 'suspended') void ctx.resume();
  }

  /** Play from `globalFrame`, replacing whatever was playing. `speed` is the preview speed. */
  seekTo(globalFrame: number, composition: Composition, speed = 1): void {
    this.stopAll();
    const ctx = this.context();
    if (ctx.state === 'suspended') void ctx.resume();
    this.voices = this.schedule(ctx, composition, globalFrame / composition.output.fps, ctx.currentTime, speed);
  }

  /**
   * Schedule every decoded sound still to come at timeline second `fromSecs`
   * onto `ctx`, with that second landing on context time `at`. Timeline time
   * passes `speed` times faster than real time. Public so a test run can
   * render the timeline into an OfflineAudioContext.
   */
  schedule(ctx: BaseAudioContext, composition: Composition, fromSecs: number, at: number, speed = 1): Voice[] {
    const voices: Voice[] = [];
    for (const { layer, timing } of collectAudibleLayers(composition)) {
      const buffer = this.decoded.get(layer.src);
      if (!buffer) continue;
      if (timing.timelineOffsetSecs + timing.durationSecs <= fromSecs) continue;

      // Seconds of this sound's output already behind the playhead.
      const skipped = Math.max(0, fromSecs - timing.timelineOffsetSecs);
      const when = at + Math.max(0, timing.timelineOffsetSecs - fromSecs) / speed;

      const source = ctx.createBufferSource();
      source.buffer = buffer;
      source.playbackRate.value = timing.playbackRate * speed;
      const gain = ctx.createGain();
      applyEnvelope(gain.gain, timing, skipped, when, speed);
      source.connect(gain).connect(ctx.destination);
      // offset and duration count buffer seconds, which pass playbackRate times per output second.
      source.start(
        when,
        timing.sourceStartSecs + skipped * timing.playbackRate,
        (timing.durationSecs - skipped) * timing.playbackRate,
      );
      voices.push({ source, gain });
    }
    return voices;
  }

  stopAll(): void {
    for (const { source } of this.voices) {
      try {
        source.stop();
      } catch {
        // already stopped
      }
      source.disconnect();
    }
    this.voices = [];
  }

  dispose(): void {
    this.stopAll();
    this.buffers.clear();
    this.decoded.clear();
    void this.ctx?.close();
    this.ctx = null;
  }
}

/**
 * Volume with linear fades, as FFmpeg's afade draws them. Output second s of
 * the sound plays at context time when + (s − skipped) / speed.
 */
function applyEnvelope(param: AudioParam, t: AudioTiming, skipped: number, when: number, speed: number): void {
  const time = (s: number) => when + (s - skipped) / speed;
  const level = (s: number) => t.volume * Math.max(0, Math.min(
    1,
    t.fadeInSecs > 0 ? s / t.fadeInSecs : 1,
    t.fadeOutSecs > 0 ? (t.durationSecs - s) / t.fadeOutSecs : 1,
  ));

  param.setValueAtTime(level(skipped), when);
  if (t.fadeInSecs > skipped) param.linearRampToValueAtTime(level(t.fadeInSecs), time(t.fadeInSecs));
  if (t.fadeOutSecs > 0) {
    const fadeOutStart = t.durationSecs - t.fadeOutSecs;
    if (fadeOutStart > skipped) param.setValueAtTime(level(fadeOutStart), time(fadeOutStart));
    param.linearRampToValueAtTime(0, time(t.durationSecs));
  }
}
```

```ts
function encodeWav(buffer: AudioBuffer): Uint8Array {
  const channels = buffer.numberOfChannels;
  const frames = buffer.length;
  const bytes = frames * channels * 2;
  const view = new DataView(new ArrayBuffer(44 + bytes));
  const text = (offset: number, s: string) => {
    for (let i = 0; i < s.length; i++) view.setUint8(offset + i, s.charCodeAt(i));
  };
  text(0, 'RIFF');
  view.setUint32(4, 36 + bytes, true);
  text(8, 'WAVE');
  text(12, 'fmt ');
  view.setUint32(16, 16, true);
  view.setUint16(20, 1, true);
  view.setUint16(22, channels, true);
  view.setUint32(24, buffer.sampleRate, true);
  view.setUint32(28, buffer.sampleRate * channels * 2, true);
  view.setUint16(32, channels * 2, true);
  view.setUint16(34, 16, true);
  text(36, 'data');
```

```ts
import { ALL_FORMATS, AudioBufferSink, BlobSource, Input } from 'mediabunny';

/** Decode a file's primary audio track with WebCodecs, for containers decodeAudioData refuses. */
async function decodeWithMediabunny(blob: Blob, ctx: BaseAudioContext): Promise<AudioBuffer> {
  const input = new Input({ source: new BlobSource(blob), formats: ALL_FORMATS });
  try {
    const track = await input.getPrimaryAudioTrack();
    if (!track || !(await track.canDecode())) throw new Error('no decodable audio track');
    const chunks: AudioBuffer[] = [];
    for await (const { buffer } of new AudioBufferSink(track).buffers()) chunks.push(buffer);
    const channels = Math.max(...chunks.map((c) => c.numberOfChannels));
    const length = chunks.reduce((n, c) => n + c.length, 0);
    const out = ctx.createBuffer(channels, length, chunks[0].sampleRate);
    let offset = 0;
    for (const chunk of chunks) {
      for (let ch = 0; ch < channels; ch++) {
        out.copyToChannel(chunk.getChannelData(Math.min(ch, chunk.numberOfChannels - 1)), ch, offset);
      }
      offset += chunk.length;
    }
    return out;
  } finally {
    input.dispose();
  }
```
